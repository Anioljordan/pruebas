CASA PINTIÑO — WEB
==================

Archivos principales:
- index.html
- style.css
- script.js
- img/

IMÁGENES A SUSTITUIR
--------------------
La web incluye placeholders locales para que funcione desde el primer momento.
Sustituye los archivos dentro de /img manteniendo exactamente estos nombres:

- casapintinologo.jpg  → logo real del restaurante
- hero.jpg             → imagen principal grande del restaurante o de un plato de brasa
- plato-1.jpg          → ideal: pulpo gallego
- plato-2.jpg          → ideal: pata de pulpo / brasa
- plato-3.jpg          → ideal: entrecot o carne a la brasa
- galeria-1.jpg
- galeria-2.jpg
- galeria-3.jpg
- galeria-4.jpg
- galeria-5.jpg
- favicon.png          → favicon definitivo

Las imágenes de platos funcionan mejor en formato horizontal 4:3 y el hero en 16:9 o más panorámico.

HORARIO
-------
No se proporcionó un horario. Por eso la web muestra "Consulta l'horari actual trucant al restaurant".
Cuando tengas el horario, edita ese texto en index.html y añade openingHoursSpecification al JSON-LD.

GOOGLE
------
- Google Maps está integrado mediante la dirección y el botón utiliza el enlace proporcionado.
- Google Analytics: añade el snippet oficial al final de index.html cuando tengas el ID real.
- Google Search Console: añade la metaetiqueta real de verificación en el <head>.

SEO / DOMINIO
-------------
Cuando tengas el dominio definitivo, añade:
- og:url
- og:image con URL absoluta
- url en el JSON-LD
- canonical
